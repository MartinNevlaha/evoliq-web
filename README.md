# Evoliq — Next.js landing (Vercel-ready)
- Integrované tvoje logo v `/public` a v Navbar + Hero.
- Kontakt formulár posiela e-mail cez Resend (API route).

## Env vars
RESEND_API_KEY=...  # z https://resend.com
CONTACT_TO_EMAIL=you@yourdomain.com

## Spustenie
npm install
npm run dev

## Deploy na Vercel
Importni repo z GitHubu a v Project Settings pridaj env vars.
